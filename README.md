# agile-final-project
## Stakeholder requirements
Following are the requirements from your stakeholders that you should use to create the user stories in Kanban board.

1. * [ ] Need the ability to create a product in the catalog.
1. * [ ] Need the ability to retrieve a product from the catalog.
1. * [ ] Need the ability to update a product in the catalog.
1. * [ ] Need the ability to delete a product from the catalog.
1. * [ ] Need the ability to Like a product in the catalog.
1. * [ ] Need the ability to Dislike a product in the catalog.
1. * [ ] Need the ability to list all products in the catalog.
1. * [ ] Need the ability to query a subset of products in the catalog.
1. * [ ] Must be hosted in the cloud.
1. * [ ] Must have automation to deploy new changes to the cloud.
